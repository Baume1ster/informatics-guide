Информатика для первокурсника

О проекте

Данный проект представляет собой небольшой справочник по информатике, предназначенный для студентов первого курса.

Цель проекта

Собрать основные понятия, определения и практические примеры по выбранной теме информатики.

Автор

Denis

Тема

Системы счисления.

Содержание проекта

README.md — описание проекта.

glossary.md — словарь основных терминов.

examples.md — разобранные примеры.

sources.md — использованные источники.

.gitignore — правила исключения временных файлов.

questions.md — вопросы для самопроверки.

Как пользоваться справочником

Как пользоваться справочником

1. Сначала прочитайте README.md, чтобы понять цель проекта и его структуру.
2. Затем откройте glossary.md и изучите основные термины по системам счисления.
3. После этого перейдите к examples.md и разберите практические примеры перевода чисел.
4. Ознакомьтесь с sources.md, чтобы узнать, какие материалы использовались при подготовке справочника.
5. В завершение откройте questions.md и проверьте свои знания с помощью вопросов для самопроверки.
## Самопроверка

Ответить на вопросы по теме можно в файле [questions.md](questions.md).
